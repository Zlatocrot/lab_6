## ***Условие задачи***

Написать программу, которая отвечает на вопрос (сообщение типа "Да"/"Нет") делятся ли введенные пользователем числа нацело.

## ***1. Алгоритм и блок-схема***

* ***Алгоритм***
  1. **Начало**
  2. **Задать исходные данные:**
     - A (первое число);
     - B (второе число).
  3. **Проверка деления на ноль:**
     - Если B == 0, вывести сообщение об ошибке деления на ноль.
  4. **Проверка деления нацело:**
     - Если A % B == 0, вывести "Да, числа делятся нацело".
     - Иначе вывести "Нет, числа не делятся нацело".
  5. **Конец**

## ***2. Реализация программы***

```c
int dz(int A, int B) 
{
    if (B == 0) 
    {
        printf("Ошибка: деление на ноль\n");
    }
    else 
    {
        printf("%s\n", (A % B == 0) ? "Да, числа делятся нацело" : "Нет, числа не делятся нацело");
    }
    return 0;
}
```
## 3. Результаты работы программы
 - Введите число A: 6
 - Введите число B: 3
 - Нет, числа не делятся нацело
